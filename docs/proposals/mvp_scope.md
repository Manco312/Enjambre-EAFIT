# MVP Scope

## 🟢 IN — Alcance Incluido
*Funcionalidades, reglas o entregables que sí forman parte del MVP.*

- Registro y gestión de miembros por grupo estudiantil.
- Carga de datos con validación automática de campos (evitar errores de tipado).
- Módulo de control de permanencia (seguimiento de requisitos por miembro).
- Panel de administración para Desarrollo Estudiantil.
- Roles diferenciados: administrador (Desarrollo Estudiantil) y junta directiva (por grupo).
- Exportación de reportes consolidados (ej. CSV/Excel).
- Autenticación básica de usuarios.
- Notificaciones y avisos automáticos de permanencia.

---

## 🔴 OUT — Fuera de Alcance
*Elementos explícitamente excluidos del alcance actual. Esto evita expectativas incorrectas.*

- Integración directa con sistemas académicos oficiales de EAFIT (SGA/Banner).
- Gestión financiera o presupuestal de los grupos estudiantiles.
- Aplicación móvil nativa (solo versión web responsive).
- Automatización de procesos de selección o gobernanza interna de los grupos.
- Migración histórica de datos anteriores a la fecha de inicio del proyecto.
